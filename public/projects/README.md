# Project screenshots

Drop project screenshots here, e.g. `project-1.png`, then reference them
in `src/data/projects.ts` by setting `image: '/projects/project-1.png'`
on that project's entry.

Recommended size: ~1600×1000px (16:10), optimized as `.png` or `.webp`.
If a project has no `image` set, the site renders a designed placeholder
instead of a broken image.
